
# Alpha Omega Inversion - Remise finale

## Description

Alpha Omega Inversion est un jeu Unity solo qui combine une partie 2D et une partie 3D dans un univers de science-fiction.

Le joueur contrôle Bob, un astronaute qui doit progresser dans différents niveaux, éviter les dangers, éliminer les ennemis et compléter les objectifs nécessaires pour atteindre la fin du jeu.

## Versions du jeu

Le jeu est disponible sur itch.io en deux versions :

- Version Windows avec un fichier `.exe`
- Version macOS en fichier `.zip`

## Technologies utilisées

- Unity
- C#
- Git LFS

## Ouvrir le projet Unity depuis GitHub

Le projet utilise Git LFS pour certains fichiers lourds comme les modèles, sons et textures.
